# 本机采集助手使用教程

本教程用于指导普通用户安装本机采集助手，并在网页中抓取热点信息源。

## 适用范围

- 当前安装包支持 macOS。
- 公开热点源包括 36氪、百度热搜、今日头条热榜、腾讯热榜、微博热搜等。
- 抖音、小红书的作品级数据可能需要用户在本机完成平台登录，并受平台风控、验证码、接口可用性影响。

## 使用步骤

1. 打开网页，点击左侧「下载 macOS 助手」。
2. 下载 `shipinjiaoben_collector_installer.zip` 后解压。
3. 打开 `Collector_Helper_Installer.app`，按提示完成安装。
4. 回到网页，点击「检测本机助手」。
5. 显示助手已连接后，点击「抓取热点源」。
6. 在热点源列表中点击平台按钮筛选来源，或点击「打开源头」跳转到原始页面。
7. 需要把某条热点用于生成脚本时，点击「用作选题」。

## macOS 安全提示

如果 macOS 提示无法打开安装器，可以按下面方式处理：

1. 打开「系统设置」。
2. 进入「隐私与安全性」。
3. 在安全提示处选择允许打开。
4. 再次打开 `Collector_Helper_Installer.app`。

## 抖音和小红书说明

网页不会读取用户浏览器里的登录信息。作品级采集只会通过用户电脑上的本机助手进行。

- 公开热榜：通常可直接抓取或展示搜索源头。
- 抖音作品级数据：需要本机 DouK/TikTokDownloader 服务可用，并配置登录态。
- 小红书作品级数据：需要本机 XHS-Downloader 服务可用，并配置登录态。

如果只需要热点选题和源头跳转，可以先使用公开热榜；如果需要具体作品、点赞、评论、文案、热评，再配置平台登录态。

## 常见问题

### 下载助手返回 404

请确认网站发布时包含 `scripts/shipinjiaoben_collector_installer.zip`。网页下载按钮依赖这个文件。

### 检测不到本机助手

请确认已经完成安装，然后刷新网页或点击「检测本机助手」。助手默认监听：

```text
http://127.0.0.1:8765
```

### 热点源可以显示，但抖音作品抓不到

这通常说明公开热榜功能正常，但 DouK/TikTokDownloader 没有启动，或登录态不可用。先确认本机助手状态里抖音采集服务是否已连接。

### 页面能打开源头，但不能自动获取平台详情

部分平台页面需要登录、验证码或动态加载。此时网页会保留源头跳转，用户可点击到平台查看原始内容。

## 隐私说明

- AI 生成密钥只保存在当前浏览器输入框，不会写入项目文件。
- 本机采集助手运行在用户自己的电脑上。
- 网页只请求 `127.0.0.1` 的本机服务，不需要你的云端后端参与采集。
